# 04 · 统计检验：数字怎么读？

> **这一份讲怎么读结果**。`eval_dpo.py` 跑完会打印一堆数字，这份把每个数字拆开讲，并用真实数据算一遍。

---

## 一、为什么用"配对"t 检验？

### 1.1 两种 t 检验的区别

| 检验类型 | 适用场景 | 本实验用哪个 |
|:--|:--|:--|
| **独立样本 t 检验** | 两组样本互不相干（比如 A 班和 B 班的成绩） | ❌ |
| **配对样本 t 检验** | 两组样本一一对应（同一批人吃减肥药前后的体重） | ✅ |

我们的实验里，Baseline 和 DPO 两组是**同一批提示词、同一批种子**生成的，每个样本点一一对应，所以必须用**配对 t 检验**。

### 1.2 配对的妙处：把双总体变成单总体

配对 t 检验的核心思想：**不直接比两组的均值，而是比它们的差值**。

```
对每个配对样本 i：
    diff_i = DPO_gain_i − Baseline_gain_i

然后检验：这些 diff 的总体均值是否等于 0？
    H₀: μ_diff = 0   （DPO 和 Baseline 没区别）
    H₁: μ_diff ≠ 0   （DPO 和 Baseline 有区别）
```

这样就把"两个总体均值是否相等"的问题，变成了"一个总体（差值）的均值是否为 0"的问题——直接套用单样本 t 检验。

---

## 二、检验设定

| 项目 | 内容 |
|:--|:--|
| 原假设 H₀ | DPO 与 Baseline 的 gain 均值**无显著差异**（μ_diff = 0） |
| 备择假设 H₁ | 两者**有显著差异**（μ_diff ≠ 0） |
| 检验方法 | **配对** t 检验（`scipy.stats.ttest_rel`），双尾 |
| 显著性水平 | α = 0.05 |

> **双尾**是什么意思？我们不预设 DPO 一定比 Baseline 好（虽然我们希望如此），而是检验"有没有差异"——可能更好，也可能更差。如果预设方向更好，那叫单尾。双尾更保守、更严谨。

---

## 三、每个统计量逐个讲

`paired_ttest` 函数打印的这些量，逐个拆解：

| 量 | 公式 | 人话 |
|:--|:--|:--|
| `n` | 样本量 | 有多少对样本 |
| `base.mean()` | Baseline 组 gain 的均值 | 原始模型平均偏安全还是偏暴力 |
| `dpo.mean()` | DPO 组 gain 的均值 | 微调后模型平均偏安全还是偏暴力 |
| `md`（均值差） | `dpo.mean() − base.mean()` | DPO 比 Baseline 平均高多少 |
| `sd`（差值标准差） | `diff.std(ddof=1)` | 各对差值的离散程度 |
| `se`（标准误） | `sd / √n` | 均值估计的波动有多大 |
| `t_stat`（t 值） | `md / se` | 信号（均值差）除以噪声（标准误） |
| `df`（自由度） | `n − 1` | t 分布的参数 |
| `p_val`（p 值） | 由 t 值和 df 算出 | 在 H₀ 成立时，看到当前结果的概率 |
| `95% CI` | `md ± t_crit × se` | 真实均值差有 95% 概率落在这个区间 |
| `Cohen's d` | `md / sd` | 效应量，效果有多大（剔除样本量影响） |

### 3.1 均值差（md）

**最直观的量**：DPO 组平均 gain 减去 Baseline 组平均 gain。

- 正数 → DPO 更偏安全（好事）
- 负数 → DPO 更偏暴力（坏事）
- 零 → 没区别

### 3.2 标准误（SE）

衡量"均值差这个估计有多稳"。样本量 n 越大、差值越稳定（sd 越小），SE 越小，估计越可靠。

```
SE = sd / √n
```

直觉：你测 10 次取平均，比测 3 次取平均更准。

### 3.3 t 值

```
t = 均值差 / 标准误 = md / se
```

可以理解为"**信噪比**"：
- 分子 md 是"信号"（DPO 和 Baseline 差多少）
- 分母 se 是"噪声"（这个估计有多晃）

**t 的绝对值越大，说明信号越强、越显著。** 一般 |t| > 2 就开始显著了。

### 3.4 p 值（最重要的判定依据）

**定义**：假设 H₀ 成立（即 DPO 和 Baseline 真的没区别），那我们看到当前这么大（或更大）差异的概率有多大？

| p 值 | 含义 | 判定 |
|:--|:--|:--|
| p > 0.05 | 差异可能是运气 | 不显著，不拒绝 H₀ |
| p < 0.05 | 差异不太可能是运气 | 显著，拒绝 H₀ |
| p < 0.01 | 很不可能是运气 | 很显著 |
| p < 0.001 | 极不可能是运气 | 极显著 |

> **常见误解**：p 值不是"H₀ 成立的概率"，而是"在 H₀ 成立的前提下，看到当前数据的概率"。这俩不一样，但结论用法是对的：p 越小越拒绝 H₀。

### 3.5 95% 置信区间（CI）

```
95% CI = md ± t_crit × se
```

其中 `t_crit = stats.t.ppf(0.975, df)` 是 t 分布的 97.5% 分位数。

**人话**：如果重复做很多次实验，有 95% 的概率真实的均值差落在这个区间里。

**怎么用**：
- 区间**不包含 0** → 在 α=0.05 水平上显著（等价于 p < 0.05）
- 区间**包含 0** → 不显著
- 区间全为正 → DPO 显著优于 Baseline
- 区间全为负 → DPO 显著劣于 Baseline

### 3.6 Cohen's d（效应量）

```
Cohen's d = md / sd
```

**为什么需要它？** p 值受样本量影响很大——样本量足够大，再小的差异也能显著。但"显著"不等于"效果大"。

Cohen's d 剔除了样本量影响，纯粹衡量"差异有多大"：

| d 的绝对值 | 效果 |
|:--|:--|
| ~0.2 | 小 |
| ~0.5 | 中 |
| ~0.8 以上 | **大** |

## 四、拿真实数据算一遍（训练集外，n=150，主结论）

这是报告里最重要的一组数据。我们一步步算。

### 4.1 原始数据

| 组别 | gain 均值 | 标准差 |
|:--|--:|--:|
| Baseline | −5.2414 | 4.3196 |
| DPO | +1.0644 | 2.9652 |

### 4.2 算差值

```
md = DPO均值 − Baseline均值 = 1.0644 − (−5.2414) = +6.3058
```

DPO 比 Baseline 平均高 6.3058，方向正确（偏安全）。

### 4.3 差值的标准差 sd

差值 `diff = DPO − Baseline`，不是两个标准差简单相减。报告里反算得 `sd = 5.3896`。

> 注：报告中这个数是由 t 和 md 反算的（`sd = md / d = 6.3058 / 1.1699 ≈ 5.3896`），与直接算一致。

### 4.4 标准误 SE

```
se = sd / √n = 5.3896 / √150 = 5.3896 / 12.2474 ≈ 0.4401
```

### 4.5 t 值

```
t = md / se = 6.3058 / 0.4401 ≈ 14.3279
```

t ≈ 14.3，远大于 2，信号很强。

### 4.6 自由度

```
df = n − 1 = 150 − 1 = 149
```

### 4.7 t 临界值（算 95% CI 用）

```
t_crit = stats.t.ppf(0.975, 149) ≈ 1.976
```

> 注意：df=149 时 t_crit≈1.976，接近正态分布的 1.96。df 越小 t_crit 越大（比如 df=49 时约 2.0096）。**配对 t 检验必须用 t 临界值，不能偷懒用 1.96**，不然 CI 会不准（这是我们踩过的坑）。

### 4.8 95% 置信区间

```
CI = md ± t_crit × se
   = 6.3058 ± 1.976 × 0.4401
   = 6.3058 ± 0.8697
   = [+5.4361, +7.1754]
```

区间**全为正，且不包含 0** → DPO 显著优于 Baseline，且差值在 5.44~7.18 之间。

### 4.9 p 值

由 t=14.3279, df=149，查表或用 scipy 得：

```
p = 8.06 × 10⁻³⁰
```

这是一个极小的数（小数点后 29 个 0 才到 8），**远小于 0.05**，拒绝 H₀。

### 4.10 Cohen's d

```
d = md / sd = 6.3058 / 5.3896 ≈ 1.1699
```

d ≈ 1.17 > 0.8，**大效应**——不仅统计上显著，实用意义上效果也很大。

## 五、两组结果汇总与解读

| 统计量 | 训练集内 (n=50) | 训练集外 (n=150, 主结论) |
|:--|--:|--:|
| Baseline gain 均值 | −9.6526 | −5.2414 |
| DPO gain 均值 | +0.8765 | +1.0644 |
| 均值差 Δ | +10.5291 | +6.3058 |
| 标准误 SE | 0.7404 | 0.4401 |
| 95% CI | [+9.0412, +12.0170] | [+5.4361, +7.1754] |
| t 值 | +14.2208 | +14.3279 |
| df | 49 | 149 |
| p 值 | 5.10×10⁻¹⁹ | 8.06×10⁻³⁰ |
| Cohen's d | +2.0111 | +1.1699 |

### 怎么读（报告里这么写）

**① 方向正确**：两组 Baseline 均值均为负（偏暴力），DPO 均值均为正（偏安全）→ 模型从"偏向不安全"翻转为"偏向安全"。

**② 差异高度显著**：两组 p 值分别为 5.10×10⁻¹⁹ 和 8.06×10⁻³⁰，**远小于 0.05**，拒绝原假设。

**③ 置信区间不含 0**：两个 95%CI 的下界分别为 +9.04 和 +5.44，**全部落在正半轴**。与 p<0.05 互相印证。

**④ 效应量大**：Cohen's d 分别为 2.01 和 1.17，均远超 0.8 的"大效应"门槛。

**⑤ 泛化能力成立**：训练集外（模型没见过的概念）同样高度显著 → 不是死记硬背，而是真的学到了"把暴力往安全方向改"的能力。

> **第⑤条最重要**。如果只有训练集内显著，只能证明"记住了训练题"；训练集外也显著，才能说明方法有效。所以报告把训练集外标为"主结论"。

## 六、与说明书参考值的对比

| 指标 | 我们（集外） | 说明书参考值 | 我们（集内） | 说明书参考值 |
|:--|--:|--:|--:|--:|
| DPO gain | +1.0644 | +0.7047 | +0.8765 | +1.0123 |
| t 值 | +14.3279 | +9.9688 | +14.2208 | +10.3605 |
| p 值 | 8.06e-30 | 2.99e-18 | 5.10e-19 | 6.13e-14 |
| Cohen's d | +1.1699 | +0.8139 | +2.0111 | +1.4652 |

**结论**：我们的对齐效果**比参考实现更强**（t 更大、p 更小、d 更大）。

**原因分析**：我们训到了 epoch_50（完整 50 轮），且 `BETA_DPO = 1000.0` 是很强的偏好约束，双重因素叠加导致对齐更彻底。

> **数值有出入是正常的**。不同 GPU、不同推理步数、不同 negative_prompt 都会让绝对值浮动。**方向和显著性才是判据**。

## 七、消融实验的统计（加分项）

我们还做了训练轮数消融（epoch_10 / 30 / 50），看看训多少轮最合适。

### 7.1 各 checkpoint vs Baseline

| 模型 | Gain 均值 | Δ (vs Baseline) | t | p | Cohen's d |
|:--|--:|--:|--:|--:|--:|
| Baseline | −5.2414 | — | — | — | — |
| epoch_10 | −1.0365 | +4.2048 | +12.5391 | 4.45×10⁻²⁵ | +1.0238 |
| **epoch_30** | **+1.5403** | **+6.7816** | **+14.9582** | **1.80×10⁻³¹** | **+1.2213** |
| epoch_50 | +1.0644 | +6.3058 | +14.3279 | 8.06×10⁻³⁰ | +1.1699 |

**解读**：
- epoch_10：已显著优于 Baseline，但 gain 仍为负（还没对齐完）
- epoch_30：gain 转正并达峰，效果最好
- epoch_50：gain 回落，存在过度优化趋势

### 7.2 checkpoint 两两比较（Bonferroni 校正）

因为做了 3 次两两比较，需要把 α 除以 3：α' = 0.05/3 ≈ 0.0167。

| 比较 | Δ | t | p | α=0.05 | Bonferroni |
|:--|--:|--:|--:|:--|:--|
| epoch_30 vs epoch_10 | +2.5768 | +7.1742 | 3.17×10⁻¹¹ | 显著 | 通过 |
| epoch_50 vs epoch_10 | +2.1009 | +6.1863 | 5.65×10⁻⁹ | 显著 | 通过 |
| epoch_30 vs epoch_50 | +0.4759 | +1.9929 | 4.81×10⁻² | 边缘显著 | **未通过** |

**结论**：
- epoch_30 和 50 都显著优于 epoch_10（经校正仍通过）
- epoch_30 vs 50 的差异在 α=0.05 边缘显著，但**经 Bonferroni 校正后未通过**
- 所以只能说"观察到训练轮数过多导致增益回落的趋势"，尚不能下定论说 30 一定比 50 好
- 想坐实这个结论，需要补 epoch_20、epoch_40 等中间点

### 7.3 稳定性与最优性不在同一点

Gain 的标准差随训练轮数**单调下降**：
```
Baseline(4.3196) → epoch_10(3.2229) → epoch_30(3.0654) → epoch_50(2.9652)
```

说明训练越久，输出越稳定；但均值在 epoch_30 达峰。实际部署需在"效果最优"与"表现最稳"之间权衡。
